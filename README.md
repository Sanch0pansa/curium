# Curium

Curium - инструмент для освоения навыков на основе ИИ-агента и небольшого веб-приложения.

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и Python 3.13+.

```bash
uv sync
uv run poe start
```

Приложение откроется на http://localhost:8000.

## Структура проекта

```
courses/{course}/        курсы (в git не попадают)
  index.json             цель, экзамен, список уроков и статусы
  lessons/01-slug.md     уроки, практика в конце того же файла
  work/                  черновики агента, приложение их не показывает
src/curium/              бэкенд на FastAPI
src/curium/static/       фронтенд: HTML, CSS, VanillaJS
src/curium/mcp_server.py MCP-инструмент для работы с index.json
.mcp.json                подключение MCP-сервера к агенту
.claude/skills/          скиллы агента
CLAUDE.md                правила проекта и формат курса
```

Подробный формат `index.json` и уроков описан в [CLAUDE.md](CLAUDE.md).

## Как пользоваться

1. Откройте агента (Claude Code) в корне проекта.
2. Напишите, что хотите выучить: "хочу освоить Go" или "научите меня основам статистики". Подхватится скилл `curium-course`.
3. Агент задаст до 5 вопросов о вашем уровне, сузит цель до достижимой и соберёт курс. Это занимает несколько минут.
4. Откройте приложение, выберите курс и читайте уроки. В конце каждого нажимайте "Прочитано".
5. Чтобы проверить себя, напишите агенту "проэкзаменуйте меня по уроку 3". Он задаст вопросы, добьётся объяснения своими словами и допустит к практике.
6. После выполнения практики отправьте результат агенту. Если он может её оценить, то поставит статус сам, если нет (например, нужна устная речь), то честно скажет об этом.
7. Когда курс пройден, попросите итоговую проверку цели. Она займёт не больше 3-4 итераций с комментариями.

Статусы `is_examinated` и `practice_completed` выставляет только агент. Кнопка "Прочитано" в приложении меняет только `is_read`.

## Скиллы

Скилл — это папка с файлом `SKILL.md`, которую Claude Code подхватывает сам.

Сейчас в проекте один скилл: [curium-course](.claude/skills/curium-course/SKILL.md). Он ведёт агента через семь этапов: цель, ресерч, компетенции, план, уроки, аудит, результат. Каждый этап идёт отдельным сабагентом, который читает файлы из `work/`.

## MCP-инструмент

Агент меняет `index.json` только через MCP-сервер [mcp_server.py](src/curium/mcp_server.py), а уроки и файлы в `work/` правит напрямую. Сервер подключён через [.mcp.json](.mcp.json) и запускается самим Claude Code, поэтому отдельной команды не требуется. При первом запуске агент попросит подтвердить доступ к проектному серверу `curium`.

Доступны три инструмента:

- `create_course` создаёт `index.json` с целью, описанием экзамена и списком уроков. Для каждого урока указывается, нужны ли экзамен и практика, и от этого зависит, будут ли соответствующие статусы `false` или `null`.
- `set_lesson_status` меняет одно из полей `is_read`, `is_examinated`, `practice_completed` у урока с заданным номером.
- `get_lesson_status` возвращает статусы урока.

Номера уроков считаются с единицы, в порядке списка в `index.json`.
