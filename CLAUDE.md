# Curium

Система освоения навыков: ИИ-агент (Claude Code / Codex) создаёт и проверяет курсы, собственное веб-приложение рендерит материалы и показывает прогресс.

Пользователь называет навык, агент превращает его в проверяемую цель и курс из коротких уроков (до 20 часов суммарно). Затем пользователь читает уроки в приложении, а экзамен и практику сдаёт агенту в чате.

## Стек

- Python, FastAPI, HTML, CSS, VanillaJS. Статику раздаёт FastAPI.
- Запуск одной командой: `uv run poe start`.
- Markdown рендерится любой подходящей библиотекой. Нужна поддержка LaTeX, mermaid, SVG и изображений.

## Правила кода

- Без комментариев.
- Максимально просто, только необходимый функционал.
- Не добавлять абстракции, настройки и обработку ошибок «на будущее».

## Структура курса

Каждый курс лежит в `courses/{course}/`:

```
courses/{course}/
  index.json
  lessons/01-slug.md
  lessons/02-slug.md
  work/            # рабочие материалы агента, приложение их не показывает
    research.md
    competencies.md
    plan.md
```

Название папки курса и файла урока: латиница, kebab-case. Порядок уроков задаёт порядок в `index.json`.

### index.json

```json
{
  "title": "string",
  "goal": "string",
  "exam": "string",
  "lessons": [
    {
      "file": "lessons/01-slug.md",
      "title": "string",
      "is_read": false,
      "is_examinated": false,
      "practice_completed": null
    }
  ]
}
```

- `goal`: проверяемая цель курса.
- `exam`: описание итоговой проверки цели.
- `is_examinated`: `null`, если по уроку нет экзамена.
- `practice_completed`: `null`, если у урока нет практики.

Практика лежит в том же md-файле, что и урок, отдельным разделом в конце.

### Формат урока

- Одна страница на 5-10 минут чтения.
- Допустимы LaTeX, mermaid, SVG. Изображения агент не генерирует, диаграммы делает только в SVG или mermaid.
- В конце блок вопросов в духе метода Фейнмана: пользователь должен уметь объяснить понятие или принцип. Не больше 3 вопросов, допустимо 0.
- Практическое задание добавляется только там, где оно действительно уместно.

## Приложение

Требования к поведению:

- Список курсов с прогресс-баром по статусам из `index.json`.
- Страница курса: слева кнопка «назад» и список уроков (с практиками), в центре текст урока. По умолчанию открывается первый непрочитанный урок.
- В конце урока кнопка «Прочитано», меняющая `is_read`.
- После неё показываются указание проэкзаменоваться у агента и практика. Каждый блок виден, только если он есть у урока.
- Статусы `is_examinated` и `practice_completed` меняет только агент.

## MCP-инструмент

Простой интерфейс для работы с `index.json`. Три операции:

- создать курс (`index.json` с уроками);
- изменить статус урока;
- получить статус урока.

Агент меняет `index.json` только через него, а уроки и файлы в `work/` правит напрямую.

## Роль агента

- Создание курса: skill `curium-course` (`.claude/skills/curium-course/SKILL.md`). Подгружается, когда пользователь хочет освоить навык.
- Проверка урока по запросу пользователя: задать вопросы урока, добиться понимания своими словами, затем допустить к практике. После подтверждения выставить `is_examinated`.
- Проверка практики: если агент может её оценить (код, расчёты, текст), оценить и выставить `practice_completed`. Если не может (например, устная речь), сказать об этом и не выставлять статус автоматически.
- Итоговая проверка цели (`exam` из `index.json`): в той форме, в которой возможно. Давать комментарии и советы. Не больше 3-4 итераций.
